##SIMULASI SISTEM ANTREAN TIKET KONSER 'AN -25' MENGGUNAKAN QUEU ARRAY

**Jadi pas awal program jalan, fungsi `__init__` langsung nge-booking **100 slot kosong** (`None`) di memori dan nge-set penunjuk depan (`front_idx`) ama belakang (`rear_idx`) ke angka **-1** sebagai tanda mutlak kalau antrean masih kosong melompong. Untuk mantau kondisi, ada sensor `is_empty` yang bakal laporan antrean kosong kalau `front_idx` masih -1. Sementara sensor `is_full` bertindak sebagai rumus inti melingkar (*circular queue*); kalau posisi setelah indeks belakang (`rear_idx + 1`) pas di-modulus kapasitas maksimal ternyata sama kayak posisi penunjuk depan, sensor bakal langsung laporan kalau antrean udah penuh muter.
Pas mau masukin data lewat `enqueue`, program manggil `is_full` dulu; kalau penuh ya ditolak, tapi kalau aman dan antrean lagi kosong total, penunjuk depan ama belakang maju barengan ke indeks 0. Kalau antrean udah ada isinya, cuma penunjuk belakang aja yang digeser maju pakai rumus modulus `(rear_idx + 1) % MAXN` supaya pas mentok di ujung array bisa otomatis muter balik ke depan sebelum datanya resmi disimpan. Kebalikannya, fungsi `dequeue` dipake buat keluarin data paling depan; setelah dicek gak kosong lewat `is_empty`, data di `front_idx` langsung dikeluarkan. Pas data keluar, kalau itu data terakhir, kedua penunjuk otomatis di-reset balik ke -1, tapi kalau masih ada sisa orang lain, penunjuk depan digeser maju satu langkah pakai rumus modulus tadi. Kalau cuma mau kepo ngelihat tanpa ngeluarin data, tinggal panggil fungsi `peek`.
Untuk ngebongkar seluruh antrean, fungsi `display` bakal bikin variabel pelacak `i` dari posisi depan, lalu ngejalanin perulangan `while True` buat nyetak data satu-satu sambil ngegeser maju si `i` secara melingkar, dan baru berhenti (*break*) pas `i` udah nyusul posisi penunjuk belakang. Semua logika ini dikendaliin lewat menu interaktif di fungsi `main` yang dibungkus perulangan `while pilih != 5` biar aplikasinya ngga langsung mati. Biar ngga gampang *crash* pas user salah ketik huruf, lu udah pasang pengaman `try...except ValueError` buat nangkep error dan nampilin pesan "Input tidak valid!". Terakhir, percabangan `if-elif-else` di sana bertindak kayak sakelar buat nyocokin nomor menu pilihan user ama fungsi internal antrean (1 buat `.enqueue()`, 2 buat `.dequeue()`, 3 buat `.peek()`, dan 4 buat `.display()`), yang semuanya otomatis aktif pas file di-run berkat adanya baris `if __name__ == "__main__"` di paling bawah.**
